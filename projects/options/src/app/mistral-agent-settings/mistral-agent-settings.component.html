What is Mistral Agent Classification?

After a sidebar summary appears, it will be sent to a configured Mistral agent for classification. The agent will return 5 labels that will be displayed beside the summary.

Requirements:

  • Mistral must be selected as the provider
  • Valid Mistral API key
  • Valid agent ID and version
  • Agent must return a JSON array of exactly 5 nonempty strings

Note: Popup summaries will NOT trigger classification. Classification failures will leave the summary visible and show a separate error in the sidebar.
